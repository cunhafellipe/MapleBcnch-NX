# 開發日誌

這個目錄記錄**每一輪做了什麼、憑什麼這麼說、以及沒做什麼**。

檔名是日期（`YYYY-MM-DD.md`）。同一輪有多個主題就寫在同一篇；跨天就開新的一篇。

寫的時候有兩個要求，都是被教訓換來的：

**1. 只寫驗證過的事，並說明是怎麼驗的。**
寫「測試通過」等於沒寫。寫「存檔後重開行程，從磁碟讀回來的值是 31337」才是寫。
專案裡到處是註解宣稱已驗證的行為，其中不少是錯的——真正的證據是實際跑一次。

**2. 沒做的事要寫下來。**
沒跑到的、沒看到的、知道有問題但決定不動的。缺口的輪廓會被時間沖淡，
寫下來它就還在。
