## 2. 對標的「設定」到底是什麼 —— 答案很窄

`SkillForm.Designer.cs` 只有 **5 個控制項**：`panel1`、`panel2`、
`comboBox1`、`label1`（"Hotkey Settings"）、`label2`（"Use List"）。

**可調的設定只有一個：熱鍵字母。**

- `SkillListGrid`（`SkillForm.cs:51`）：可施放技能清單，三欄 **id / 圖示 / 名稱**
- `comboBox1`：點一列才浮現，**選項硬寫死 A–Z 共 26 個字母**
  （`SkillForm.Designer.cs:50`），不是任意按鍵
- `UseListGrid`（`SkillForm.cs:60`）：綁定結果，四欄 id / 圖示 / 名稱 / **熱鍵**

**「哪些技能算可施放」是這個表唯一的過濾**（`SkillForm.cs:101-106` PreBB 分支、
`:120-126` 否則），四個條件全中才列：

1. id 不以 `'0'` 開頭
2. 有 `hit`
3. 有碰撞框：PreBB 分支要 `level/1/lt`，否則要 `common` **且** `common/lt`
4. 有 `effect`

## 3. 綁定的兩條互斥規則（`SkillForm.cs:156-162`）

```
移除所有 skill id 相同 的既有綁定      → 一個技能只能綁一個鍵
移除所有 hotkey  相同 的既有綁定      → 一個鍵只能綁一個技能
append 新的一列，然後從整張表重建整個字典   (:168-174)
```

**熱鍵不落地**：字典只在記憶體裡，重開 SkillForm 綁定就沒了（表單是 Hide 不是 Close，`:42-46`）。

## 5. ⚠️ 兩條傷害路徑互斥 —— 這是最容易寫錯的地方

| | `MultiStrike == true` | `MultiStrike == false` |
|---|---|---|
| 哪些技能 | 除 `1121008`/`1001005`/`1311012` 外的全部（`Skill.cs:168-178`）| 恰好那三個 |
| `SkillCollision` 建立了嗎 | 是，但**是空的** —— `Skill.cs:462-474` 只呼叫 `Dead()`，從不呼叫 `Collision()`，`:480-481` 的 `OnCollision` 直接 return | 是，真的生效 |
| `MobCollision` 建立了嗎 | 是（`:190-204` 在 `if (Skill.MultiStrike)` 裡），**傷害全部來自這條** | 否，那段程式碼根本沒跑 |
| 傷害常數 | `Skill.cs:491` `50000 + Random.Next(700000)` | `Mob.cs:806` `50000 + Random.Next(550000)` |

**兩條路徑的隨機上限不同**（700000 vs 550000）。寫錯哪一條，
出來的傷害數字分布就不對，而且沒有任何錯誤訊息。

怪物 HP 寫死：`Mob.cs:157-158` 把 WZ 的 `maxHP` 讀取註解掉，改成 `Mob.HP = 2000000`。
